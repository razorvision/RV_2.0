# Work Project

This is a RazorVision work project. Always use work credentials:

- **GitHub**: `GITHUB_PAT_WORK` (not `GITHUB_PAT_PERSONAL`)
- **n8n**: `N8N_API_KEY_WORK` / `N8N_URL_WORK` (when configured)

When setting up `.mcp.json` or other integrations, reference the work environment variables.
